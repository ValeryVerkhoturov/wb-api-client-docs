# Справочник API

Все 308 операций Wildberries Seller API, сгруппированные по 13 модулям пакета. Страницы генерируются из спецификаций OpenAPI и исходников сгенерированных клиентов, поэтому примеры вызова соответствуют коду той же версии.

| Модуль                                               | Категория               | Операций |
| ---------------------------------------------------- | ----------------------- | -------- |
| [`general`](/reference/api/general/)                 | Общее                   | 10       |
| [`items`](/reference/api/items/)                     | Работа с товарами       | 55       |
| [`orders-fbs`](/reference/api/orders-fbs/)           | Заказы FBS              | 47       |
| [`orders-dbw`](/reference/api/orders-dbw/)           | Заказы DBW              | 16       |
| [`dbs`](/reference/api/dbs/)                         | DBS                     | 21       |
| [`in-store-pickup`](/reference/api/in-store-pickup/) | Самовывоз               | 18       |
| [`orders-fbw`](/reference/api/orders-fbw/)           | Поставки FBW            | 14       |
| [`promotion`](/reference/api/promotion/)             | Маркетинг и продвижение | 42       |
| [`communications`](/reference/api/communications/)   | Общение с покупателями  | 25       |
| [`rates`](/reference/api/rates/)                     | Тарифы                  | 5        |
| [`analytics`](/reference/api/analytics/)             | Аналитика и данные      | 20       |
| [`reports`](/reference/api/reports/)                 | Отчёты                  | 24       |
| [`finances`](/reference/api/finances/)               | Документы и бухгалтерия | 11       |
