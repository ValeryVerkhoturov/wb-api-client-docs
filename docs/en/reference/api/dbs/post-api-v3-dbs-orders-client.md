# Buyer Information

```http
POST /api/v3/dbs/orders/client
```

**Base URL:** `https://marketplace-api.wildberries.ru` · **Module:** [`dbs`](/en/reference/api/dbs/) · **Section:** DBS Assembly Orders · [Specification doc ↗](https://dev.wildberries.ru/en/docs/openapi/dbs#tag/dbsAssemblyOrders/operation/postV3DbsOrdersClient)

The method allows getting information about the buyer by order ID

[Request limit](https://dev.wildberries.ru/en/docs/openapi/api-information#tag/introduction/Rate-Limits) per one seller account for **DBS assembly orders** methods:

| Period                                                           | Limit        | Interval | Burst       |
| ---------------------------------------------------------------- | ------------ | -------- | ----------- |
| 1 min                                                            | 300 requests | 200 ms   | 20 requests |
| One request with `4XX` response codes is counted as 10 requests. |

---

In [Sandbox](https://dev.wildberries.ru/en/sandbox) — maximum of 1 request per second for all **Marketplace** methods in total.

## Request body

`application/json` — schema `OrdersRequestAPI`, required

## Responses

| Code  | Description               | Schema                  |
| ----- | ------------------------- | ----------------------- |
| `200` | Success                   | `DbsOnlyClientInfoResp` |
| `400` | Bad request               | `Error`                 |
| `401` | Unauthorized              | `object`                |
| `402` | Payment required          | `object`                |
| `403` | Access denied             | `Error`                 |
| `404` | The resource is not found | `Error`                 |
| `429` | Too many requests         | `object`                |
